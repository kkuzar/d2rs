# Security policy

## Supported version

Only the latest release of d2rs gets security fixes. Update to the latest release before you report a problem.

## Report a vulnerability

Do not open a public issue for a security problem. Use the private vulnerability reporting of GitHub:

1. Open the Security tab of the repository.
2. Click "Report a vulnerability".
3. Describe the problem, the steps to repeat it, and the version of d2rs.

The maintainer reads the report and answers in it. The maintainer publishes a fix and a note after the fix is ready.

## Examples of security problems

- A save file that makes d2rs read or write a file outside the save folder.
- A save file or a game file that crashes d2rs or makes it run code.
- A workflow or a script in the repository that leaks a secret.
