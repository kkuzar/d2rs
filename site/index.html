d2rs

Character save editor for game version 1.14d (.d2s), written in Rust.

Open the web version Download for Windows (portable .exe) Source on GitHub

What it does

  • Edits character stats, skills, gold, waypoints and quests.
  • Items: create any item, edit its seed and single traits, and run a legit check.
  • Edits PlugY stash files (.d2x, .sss).
  • Seed maps for one level or a whole act, with PNG and JSON export.
  • Safe writes: every file is checked before and after saving, and the Windows app keeps backups.

Web version vs Windows app

Web versionWindows app
Runs fully in the browser. Your files never leave your computer. Saving downloads the edited file; copy it into your save folder. Maps and item pictures need your own game folder. Opens save folders directly and keeps backups of every file it writes. Has the live game reader, which exists only here.

Other systems

Pick your own game folder (its MPQ files) in d2rs for item names, item creation, item pictures and the map. Build from source: cargo install --git https://github.com/kkuzar/d2rs --locked d2rs. See the README for details.
