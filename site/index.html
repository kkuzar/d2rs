d2rs

Character save editor for game version 1.14d (.d2s), written in Rust. Edit your character, your items and your stash, and see the map of any seed.

Open the web version Download for Windows (portable .exe) Source on GitHub

Character

Change the name, class, level, experience and gold. Set the hardcore, ladder, expansion and died flags.

See the map seed, type a new seed, or make a random seed. You can keep the same map for each difficulty.

Stats

Set strength, energy, dexterity and vitality. Set the free stat points and skill points. d2rs shows life, mana and stamina.

Each value stays inside the range that the game accepts.

Skills

Set the level of each skill of your class. The list shows the character level that each skill needs.

Quests and waypoints

Complete or reset each quest in each act, for Normal, Nightmare and Hell. Open or close each waypoint.

Pending rewards (imbue, socket, personalisation) change only after a warning.

Items

Move items with drag and drop between the equipment, inventory, belt, cube, stash, mercenary and PlugY stash pages (.d2x, .sss).

  • Create unique, set, runeword, magic, rare and crafted items from the exact 1.14d tables.
  • Type a seed or reroll: d2rs builds the item again the way the game rolls it.
  • Change, add or remove single properties, sockets and the ethereal flag.
  • A "Legit" badge shows if the game can roll the item.

Map of a whole act

d2rs builds the levels from the map seed of your character, or from a seed that you type. It is a pure Rust copy of the 1.14d level generator, and the game does not have to run.

Pick the difficulty and the act. Labels show the name of each level.

Map of one level

See one level as a top-down collision map or as a game-style isometric picture. Markers show waypoints, warps and level edges.

Export one level or every level as PNG and JSON.

d2rs keeps your save file safe

  • Check before editd2rs encodes the file again and compares each byte with the original.
  • Game rulesd2rs validates each write against the load rules of the game.
  • BackupsThe desktop app backs up the old files before a write.
  • Atomic writed2rs writes a temporary file, renames it in one step, and reads it back.
  • No write while you playd2rs refuses to write while the game runs.

Web version and Windows app

Web versionWindows app
Runs fully in the browser. Your files never leave your computer. Saving downloads the edited file; copy it into your save folder. Maps and item pictures need your own game folder. Opens save folders directly and keeps backups of every file it writes. Has the live game reader, which exists only here.

Your game folder and other systems

Pick your own game folder (its MPQ files) in d2rs for item names, item creation, item pictures and the map. The pictures on this page come from the game folder of the user. Build from source on any system: cargo install --git https://github.com/kkuzar/d2rs --locked d2rs. See the README for details.
